How it works

  1. Reads the chain directly. TapeLens calls circuitInfo(id) and netlist(id) on the TapeOut processor contract through the public X Layer RPC.
  2. Simulates locally. The NAND/LATCH netlist is decoded and run in your browser, so every gate lights up as you flip inputs.
  3. Checks against the contract. “Run on X Layer” calls eval(id, inputs) on-chain and compares it bit by bit with the local result, stamped with the block number.
  4. Shares proof. The share link encodes processor, circuit and inputs — anyone opening it re-runs the same check on-chain.
